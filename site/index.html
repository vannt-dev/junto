Designed to stay honest

Policy at the center.

01

Real gates

Tests are executed by the MCP tool. A model saying “it passed” is never accepted as evidence.

exit code → verdict → transition
02

Durable state

Tasks, plans, decisions, consults, and verdicts stay in .junto/ inside your project.

03

Human checkpoint

Standard and deep plans require explicit user approval. The model cannot approve its own plan.

04

Advisory models

Anthropic, OpenAI, OpenAI-compatible endpoints (OpenRouter, Ollama, LM Studio, Gemini) or CLI-backed roles can challenge a plan—but opinions never become gates.

Two commands. No bootstrap script.
